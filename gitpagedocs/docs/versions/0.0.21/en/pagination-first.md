# GitPageDocs learning path

Read these three documents in order to understand how to set up a GitPageDocs site. This first file explains the sequence; the next file introduces installation and the final file details configuration.

## Move through the documents

Use the first, previous, next and last controls below this Markdown container. The selection changes this container without leaving the composed page or replacing the HTML map.

## Continue in focus mode

Open focus mode and change the container page. The overlay stays open and starts the selected document at its first section. Use quick navigation to find a heading in the available documents.
