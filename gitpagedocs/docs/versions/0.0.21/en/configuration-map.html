One repository, three configuration layers

The viewer combines versioned documents with shared site settings.

  1. Site

    gitpagedocs/config.json

    Languages, themes, reading controls and available versions.

  2. Version

    docs/versions/0.0.21/config.json

    Routes, menus and the relationship between page IDs and files.

  3. Content

    docs/versions/0.0.21/en/

    Markdown and optional assets translated for each enabled language.

  4. Viewer

    GitPageDocs

    Reads the selected version and language, then renders the route.

Keep every route path and menu destination consistent with the tracked files.
