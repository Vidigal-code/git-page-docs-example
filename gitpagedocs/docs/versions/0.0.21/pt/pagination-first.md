# Trilha de aprendizado GitPageDocs

Leia estes três documentos em ordem para entender como configurar um site GitPageDocs. O primeiro apresenta a sequência; o próximo explica a instalação e o último detalha a configuração.

## Percorra os documentos

Use primeiro, anterior, próximo e último abaixo deste container Markdown. A seleção troca somente este container sem sair da página composta ou substituir o mapa HTML.

## Continue no modo foco

Abra o modo foco e mude a página do container. A janela permanece aberta e inicia o documento selecionado na primeira seção. Use a navegação rápida para encontrar um título nos documentos disponíveis.
