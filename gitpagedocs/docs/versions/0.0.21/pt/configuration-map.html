Um repositório, três camadas de configuração

O visualizador combina documentos versionados com opções compartilhadas do site.

  1. Site

    gitpagedocs/config.json

    Idiomas, temas, controles de leitura e versões disponíveis.

  2. Versão

    docs/versions/0.0.21/config.json

    Rotas, menus e a relação entre IDs de páginas e arquivos.

  3. Conteúdo

    docs/versions/0.0.21/pt/

    Markdown e recursos opcionais traduzidos para cada idioma habilitado.

  4. Visualizador

    GitPageDocs

    Lê a versão e o idioma selecionados e renderiza a rota.

Mantenha caminhos de rotas e destinos de menus coerentes com os arquivos versionados.
