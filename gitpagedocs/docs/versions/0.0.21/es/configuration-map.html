Un repositorio, tres capas de configuración

El visor combina documentos versionados con opciones compartidas del sitio.

  1. Sitio

    gitpagedocs/config.json

    Idiomas, temas, controles de lectura y versiones disponibles.

  2. Versión

    docs/versions/0.0.21/config.json

    Rutas, menús y la relación entre IDs de páginas y archivos.

  3. Contenido

    docs/versions/0.0.21/es/

    Markdown y recursos opcionales traducidos para cada idioma habilitado.

  4. Visor

    GitPageDocs

    Lee la versión y el idioma elegidos y renderiza la ruta.

Mantén las rutas y los destinos de menús coherentes con los archivos versionados.
