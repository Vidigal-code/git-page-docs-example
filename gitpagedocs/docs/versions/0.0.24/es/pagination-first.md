# Recorrido de aprendizaje GitPageDocs

Lee estos tres documentos en orden para comprender cómo configurar un sitio GitPageDocs. El primero presenta la secuencia; el siguiente explica la instalación y el último detalla la configuración.

## Recorre los documentos

Usa los controles primero, anterior, siguiente y último bajo este contenedor Markdown. La selección cambia solo este contenedor sin salir de la página compuesta ni sustituir el mapa HTML.

## Continúa en modo enfoque

Abre el modo enfoque y cambia la página del contenedor. La ventana permanece abierta y comienza el documento seleccionado en su primera sección. Usa la navegación rápida para encontrar un título en los documentos disponibles.

> Versión: 0.0.24
